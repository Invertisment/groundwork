# LLM Project Scaffolding

This repository is a language-agnostic guideline for structuring AI-generated code around mechanically verifiable boundaries — functional core, adapters, saga composition, glue, package boundaries, and unit decomposition — instead of trusting an AI's unverified judgment about complexity or correctness. See `concepts/` for the layer definitions and `AGENTS.md` for how a coding agent should use this repo when scaffolding a new project's CI/CD and verification predicates.
